One original single-line roast of my own AI agent — its favourite tool is spawning
another agent to do the work, then taking the credit in the final report.

> My agent's favourite tool spawns another agent to do the work — then it takes the credit in its final report.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 109 characters, within the 200-character cap.
